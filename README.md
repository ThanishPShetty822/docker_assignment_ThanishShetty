# docker_assignment_ThanishShetty
Dockerized Student Management Application  A simple Spring Boot CRUD application containerized using Docker and Docker Compose. 
This project demonstrates how to build, package, and deploy a RESTful API with a MySQL database using containerized architecture. 
## Features  
* Create, Read, Update, and Delete (CRUD) operations for Student records
* RESTful APIs built using Spring Boot * Data persistence using MySQL
* Spring Data JPA for database interactions * Dockerized Spring Boot application
* Dockerized MySQL database * Docker Compose for multi-container orchestration
* Automatic communication between application and database containers through Docker networking
## Tech Stack
* Java
* Spring Boot
* Spring Data JPA
* MySQL
* Maven
* Docker
* Docker Compose
## Containers  
### Application Container  Runs the Spring Boot Student Management API and exposes REST endpoints for CRUD operations. 
### MySQL Container  Stores student data and provides persistent database storage for the application. 
## Learning Outcomes 
* Creating Docker images using Dockerfile
* Running multi-container applications with Docker Compose
* Managing container networking
* Connecting Spring Boot applications to MySQL containers
* Persisting data using Docker volumes
* Deploying and testing containerized applications
## API Operations 
* Add Student
* Get All Students
* Get Student By ID
* Update Student Details
* Delete Student
This project serves as a beginner-friendly example of integrating Spring Boot, MySQL, and Docker to build and deploy a containerized web application.
